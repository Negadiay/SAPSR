# Промт для Claude Fable 5.2 — реализация к 3-й опроцентовке

Работу лучше разбить на **5 сессий** — по одному блоку на сессию: так контекст не разрастается и каждая сессия читает только своё. В каждую сессию вставляется промт ниже целиком, в первой строке меняется только блок.

| Сессия | Блок | Задачи из `procentovka-3.md` |
|---|---|---|
| 1 | Б | Б1–Б5 (для Б1 положить файл куратора в `test-fixtures/curator/`) |
| 2 | Т1+Ф1 | Т1, Ф1 |
| 3 | Ф2–Ф4 | Ф2, Ф3, Ф4 |
| 4 | Ф5–Ф6 | Ф5, Ф6 |
| 5 | Т2–Т7 | Т2, Т3, Т4, Т5, Т6, Т7 и раздел Д целиком |

## Перед первой сессией (делает пользователь)

1. **Закоммитить** нынешние документы (`docs/`, `.claude/`, `.gitignore`) — чтобы diff каждой сессии Fable был отдельным.
2. **Docker Desktop**: запустить самому и сразу `docker ps`. Если поднялись контейнеры рабочего состава SAPSR — остановить их (`docker compose stop` в корне проекта) до того, как бэкенд разошлёт сообщения; если рассылка всё же ушла — предупредить тестеров. Без Docker не пройдут тесты бэкенда (Testcontainers) и сквозные прогоны.
3. **Ollama** запущена (`ollama list` показывает `qwen3.5:4b`) — нужна для Т1, Т3, Т5.
4. Сессии — **по одной**, по порядку; после каждой просмотреть отчёт и diff и закоммитить, потом следующая. Сессия 5 долгая из-за живых прогонов модели (Т3, Т5) — запускать, когда ноутбук свободен на несколько часов.
