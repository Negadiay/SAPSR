#### Б1. Нечитаемый текстовый слой → одно замечание вместо ложных

✅ 15.11.2026. Сделано по плану. Иначе: шрифт без имени превращается в пустое имя уже при извлечении (а не при выборе основного); образцы в git собраны не через MiKTeX, а прямой записью PDF с шрифтом Type 3 (`test-fixtures/hybrid/type3.py`): `tex-type3.pdf` и `unreadable-text.pdf`; коды вне таблицы T2A у шрифта TeX становятся `(cid:N)`, а не символом стандартной кодировки.

Симптом (14.11): PDF с титулом даёт «Нет титульного листа» и «Основной текст набран шрифтом „unknown“», работа возвращается за секунды.

**Причина установлена 15.11.2026** (файл `test-fixtures/curator/curator-sample.pdf`, 40 стр., курсовой проект 5 семестра; файл не в git — персональные данные студента). PDF собран MiKTeX pdfTeX без векторных кириллических шрифтов (нет пакета `cm-super`), и LaTeX подставил **растровые шрифты Type 3**: у них нет `BaseFont` (pdfminer отдаёт `fontname = "unknown"`) и нет `ToUnicode`. Имена глифов в `Encoding/Differences` — `/a0…/a255`, где число — код символа в кодировке **T2A**; pdfminer их не понимает и выдаёт `(cid:N)` или латинские символы стандартной кодировки (`Ł` вместо «и»). Текст первой страницы — мусор, поэтому титул не найден, имя шрифта «unknown», модель не получила осмысленных фрагментов, а требований 5 семестра нет (Б5) — отсюда быстрый ответ. Ещё один такой случай — собственная записка группы (`Отчёт/`, ошибка «шрифт `T2A/ftm` не найден»): это типичная ошибка студентов с LaTeX.

**Прототип проверен**: `scratchpad`-скрипт подменял расшифровку для таких шрифтов — текст всех 40 страниц восстановился полностью (51 тыс. символов, 2 нераспознанных), титул читается («Министерство образования Республики Беларусь … Кафедра интеллектуальных информационных технологий»), размер основного текста 14,3 пт (LaTeX 14pt = 14,4 пт, укладывается в 12–16).

1. **Восстановление текста растровых шрифтов TeX** — в `sapsr/document/extract.py` (рядом с `_open`). Для шрифта `PDFType3Font` без `ToUnicode`, у которого **все** имена глифов в `Differences` (кроме `.notdef`) вида `a<число>`, заполнить `cid2unicode[код] = T2A[код]`. Подключение — подкласс/обёртка `pdfminer.pdffont.PDFType3Font.__init__`, ставится один раз при импорте модуля извлечения (pdfplumber создаёт шрифты через pdfminer), с комментарием, зачем это. Таблица T2A — константа в отдельном модуле `sapsr/document/t2a.py`:
   - `0x20–0x7E` — ASCII, кроме `0x27` → `’`, `0x60` → `‘`;
   - `0x10` → `“`, `0x11` → `”`, `0x15` → `–`, `0x16` → `—`, `0x1B–0x1F` → `ff`, `fi`, `fl`, `ffi`, `ffl`;
   - `0xC0–0xFF` → `А…я` (U+0410 + (код − 0xC0));
   - `0x9C` → `Ё`, `0xBC` → `ё`, `0x9D` → `№`, `0x9F` → `§`, `0xBE` → `«`, `0xBF` → `»`;
   - прочие коды не трогать (останутся `(cid:N)`).

   Таким шрифтам дать имя `"TeX Type 3"` (`fontname`), чтобы в статистике было видно, что это растровый шрифт.
2. **Замечание о растровых шрифтах** — правило `FMT-FONT-BITMAP` в `kb/rules/20-format.yaml`: срабатывает, если больше 50 % символов основного текста набрано шрифтами `TeX Type 3` (порог — параметр). `severity: minor`, `blocking: false`, `message: "Шрифты в PDF растровые: LaTeX не нашёл векторные кириллические шрифты."`, `fix: "Установите пакет cm-super (в MiKTeX — через MiKTeX Console) и соберите PDF заново. Растровый текст размыт при увеличении, и по нему не работает поиск."`. Правило `FMT-FONT-FAMILY` для таких документов не срабатывает: семейство растрового шрифта неизвестно — в `pipeline.skipped` запись с причиной `FONT_UNKNOWN`.
3. **Качество текстового слоя** (на случай, когда восстановить не удалось — другой генератор PDF): функция в `sapsr/document/` (например `text_quality(raw) -> TextQuality`): доля символов — букв кириллицы/латиницы, цифр, пунктуации и пробелов; доля `(cid:`. Пороги — в `kb/layout.yaml`. Нечитаемо, если читаемых меньше 0,85 или `(cid:` больше 1 %. Тогда правило `DOC-TEXT-UNREADABLE` в `kb/rules/10-structure.yaml` рядом с `DOC-NO-TEXT`: `severity: critical`, `blocking: true`, `message: "Текст в файле не читается — похоже, шрифты сохранены без текста."`, `fix: "Сохраните PDF заново из Word («Сохранить как» → PDF) или из LaTeX с пакетом cm-super. Не печатайте в PDF через виртуальный принтер."`. Остальные проверки оформления и содержание не выполняются; в `pipeline.skipped` — по записи на пропущенный этап с причиной `TEXT_UNREADABLE`.
4. **Имя шрифта**: нормализация в одном месте (снять `ABCDEF+`, `PSMT`, `MT`, `,Bold`, `-Bold`, `-Italic`; `TimesNewRomanPSMT` → `Times New Roman`). Шрифт без имени (`unknown`) не участвует в выборе основного; если основного определить нельзя — `FMT-FONT-FAMILY` пропускается с причиной `FONT_UNKNOWN`, а не «шрифтом „unknown“».
5. Тесты:
   - модульные — таблица T2A (`Министерство`, `«`, `—`, `ё`), нормализация имён шрифтов, `text_quality`;
   - **файл куратора** — тест, пропускаемый при отсутствии файла (`pytest.mark.skipif`; файл не в git): титул найден, `FMT-FONT-BITMAP` есть, `STR-TITLE-PAGE` и «unknown» — нет;
   - **свой образец в git**: маленький PDF с растровым шрифтом T2A в `test-fixtures/hybrid/` — извлечь 1–2 страницы из файла куратора нельзя (персональные данные на титуле), поэтому собрать синтетический: в `generate.py` через reportlab нельзя сделать Type 3 TeX; вариант — `RawDocument` в `tests/rawdoc.py` + модульный тест на патч шрифта с поддельным словарём шрифта (`Subtype /Type3`, `Differences [192 /a192 …]`). Если MiKTeX доступен (`Отчёт/собрать.ps1` им пользуется), можно собрать одностраничный `.tex` без `cm-super`-шрифтов — только если это получается за несколько минут;
   - тест по всем `expected.json`: «unknown» не встречается в текстах замечаний.

Готово, когда: на файле куратора титул найден, текст читается, основное замечание по шрифту — `FMT-FONT-BITMAP`; содержательная проверка получает нормальный текст (после Б5 — требования 5 семестра).
