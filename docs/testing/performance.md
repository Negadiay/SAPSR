## Итог по критериям (дописано по результатам прогона 15.11.2026)

| Критерий | Результат |
|---|---|
| К3: оформление документа до 100 страниц — не дольше 60 с | **выполнен**: 114 страниц — 6,2 с; почти всё время — извлечение текста (pdfplumber), правила — доли секунды |
| К4: полный отчёт по документу до 60 страниц — не дольше 5 мин | **не выполнен** на этой машине: 12 страниц — 6,1 мин, 34 страницы — 7,9 мин. Время почти целиком — языковая модель: 15 токенов/с, на 4 ГБ видеопамяти модель работает наполовину на процессоре (`ollama ps`: 52 %/48 % CPU/GPU); извлечение утверждений — 3–5 мин, проверка 9 требований семестра — ≈ 3 мин |
| Объём базы знаний | время этапа «оформление» растёт примерно пропорционально числу правил (25 % → 100 % правил: 112 → 269 мс на 114 страницах) — на общее время не влияет |
| Объём документа | после 30–40 страниц время полного отчёта не растёт: текст в модель ограничен бюджетом профиля (60 тыс. символов), остальное помечается `BUDGET` |

Что из этого следует для работы системы: работа уходит преподавателю не позже чем через 5 мин с отчётом по оформлению (тайм-аут содержания, решение 5), итог содержания приходит следом; предел задания обработчика — 9 мин, в него полный отчёт укладывается. Чтобы выполнить К4 буквально, нужно решение: более лёгкая модель (`qwen3.5:2b` — быстрее, но хуже находит противоречия, задача 13.1), меньше обращений на проверку требований или видеокарта с бо́льшей памятью.
